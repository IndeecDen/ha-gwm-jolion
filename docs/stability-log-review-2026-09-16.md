## Длительный отказ обновления

В сессии beta.7 от 14 сентября первая ошибка `550004` появилась 15 сентября в 19:36, примерно через 24 часа после начала записи. Далее записаны 27 одинаковых ошибок с интервалом около пяти минут, последняя — в 21:46. В этой сессии восстановления нет. Следующая сессия в 21:46:14 снова успешно получает данные.

Это подтверждает повторяющийся отказ облачного API, а не остановку планировщика: попытки опроса продолжаются. В коде отсутствовало восстановление для `550004`. Время возникновения и успех новой сессии указывают на возможную проблему срока действия сессии. Точное значение серверного кода не установлено; журнал не доказывает причину завершения предыдущей сессии или падение процесса Home Assistant.

Добавлен ограниченный повторный вход при `550004` только для GET-запросов. После входа запрос повторяется один раз; повторные попытки входа ограничены интервалом 300 секунд. Параллельные запросы используют общий механизм входа. POST-команды по этому коду не повторяются.

## Временный сбой

14 сентября с 07:35 по 08:10 зарегистрированы восемь ошибок `GwmJolionApiError` без кода; в 08:15 обновление восстановилось в той же сессии. Старый формат записи не позволяет отличить сетевой сбой от некорректного ответа сервера. Теперь ошибки содержат категорию, путь метода API и HTTP-статус, когда он известен. Тела ответов и токены для этого не записываются.

Последний журнал содержит 311 успешных обновлений с интервалом около 30 секунд. Сам по себе такой интервал не доказывает сбой. Журналы интеграции не содержат ошибок браузера, поэтому причину зависания интерфейса по ним установить нельзя.

## Проверка изменений

97 автоматических тестов прошли, включая совместное восстановление двух запросов, ограничение повторных входов, отсутствие повтора POST при `550004`, запуск сохранённого профиля независимо от карточки и появление новых кнопок профилей. Реальные команды автомобилю при тестировании не отправлялись.

После установки нужна проверка не менее 48 часов с включённой записью протокола. При повторном отказе понадобятся новый JSONL и системный журнал Home Assistant; при зависании карточки — также ошибка из консоли браузера. Устранение сбоя на реальном автомобиле пока не подтверждено.
