# Jolion Locator: установка и подключение

Jolion Locator записывает GPS на головном устройстве или телефоне с **Android 8.1 и новее** и передаёт точки в интеграцию GWM Jolion. Без приложения интеграция продолжает использовать облачные координаты GWM.

**[Скачать APK 0.2.0](https://github.com/IndeecDen/ha-gwm-jolion/releases/download/0.2.0/Jolion.Locator.0.2.0.apk)** · [Все выпуски](https://github.com/IndeecDen/ha-gwm-jolion/releases) · [Настройка Яндекс.Диска](golion-locator-yandex.md)

## Установка приложения

1. Скачайте APK из GitHub Releases и перенесите его на ГУ либо откройте ссылку непосредственно на устройстве.
2. Откройте APK файловым менеджером. Если Android попросит, разрешите установку из этого источника и подтвердите установку.
3. Откройте Jolion Locator → **Настройки**. При первом запуске создаётся ключ подключения; ID по умолчанию — `jolion`. Для нескольких автомобилей используйте разные ID.
4. Выберите способ передачи и выполните инструкцию ниже или [инструкцию Яндекс.Диска](golion-locator-yandex.md).

При обновлении устанавливайте APK **поверх существующего приложения**. Так сохраняются ключи, настройки и неотправленная очередь. Удаление приложения или очистка его данных удаляют и эти сведения.

## Что означают ключи

| Значение | Где используется |
|---|---|
| **ID автомобиля** | Одинаковый в Locator и настройках интеграции; латинские строчные буквы, цифры, `_`, `-` |
| **Ключ Locator** | Одинаковый в приложении и HA; приложение создаёт его автоматически. Это не пароль GWM и не PIN |
| **OAuth-токен Яндекса** | Только для передачи через Диск; вводится в приложение, а в HA — лишь при включении автоочистки |
| **Пароль GWM / PIN** | Только настройки интеграции для облачного аккаунта и команд автомобилю |

Токен администратора Home Assistant приложению **не нужен**. QR подключения содержит ID и ключ Locator; не публикуйте его.

## Прямое подключение по HTTPS

### 1. Подготовьте Home Assistant

Установите [GWM Jolion](../README.md#установка-интеграции). HA должен открываться из сети автомобиля по **HTTPS с действующим сертификатом**, например через Home Assistant Cloud или уже настроенный внешний HTTPS-доступ.

Проверьте адрес на телефоне с мобильным интернетом и выключенным домашним Wi-Fi. Адрес вида `http://homeassistant.local:8123` для этого режима не подходит. Если внешний HTTPS-доступ организовать нельзя, используйте Диск.

### 2. Настройте Locator

В разделе **Настройки** приложения:

1. Выберите **«Напрямую HTTPS → Home Assistant»**.
2. Укажите основной адрес HA, например `https://ha.example.ru`. Не добавляйте `/lovelace`, `/config` или путь API.
3. Оставьте или задайте ID и ключ Locator.
4. Задайте **интервал отправки 5–300 секунд**. Начните с 30 секунд; для меньшей задержки при устойчивой сети можно уменьшить интервал.
5. Нажмите **«Показать QR подключения»**, чтобы перенести ID и ключ в HA.

### 3. Настройте интеграцию

1. Откройте **Настройки → Устройства и службы → GWM Jolion → Настроить**.
2. Включите пункт **«У меня установлен golion_locator»**.
3. Выберите прямую передачу **HTTPS**, введите тот же ID и ключ.
4. Для переноса ключа нажмите **«Ввести с QR»**: используйте камеру или фотографию QR из приложения. Можно заполнить поля вручную. Сканер заполняет форму; затем обязательно сохраните её.
5. Сохраните настройки интеграции.

### 4. Запустите и проверьте запись

1. В Locator нажмите **«Сохранить и начать запись»** и разрешите доступ к местоположению.
2. Откройте **Состояние**. Дождитесь первой пригодной GPS-точки, проверьте очередь и время последней передачи.
3. При успешном ответе HA приложение покажет **«Связь с Home Assistant установлена»**.
4. В HA проверьте местоположение и диагностический датчик **«Последние точки Locator»**. Добавьте карточку **GWM Jolion — Поездки** и выберите сущность местоположения автомобиля.

Интернет может отсутствовать во время поездки: точки сохраняются в приложении и отправляются позднее. В прямом режиме они удаляются из очереди после подтверждения HA. Экран Locator можно закрыть — запись работает в фоновой службе.

## Подключение через Яндекс.Диск

Этот вариант не требует открывать HA в интернет. Locator загружает зашифрованные файлы в опубликованную папку, HA самостоятельно скачивает их.

**[Пошагово: создание папки, получение OAuth-токена, настройка приложения и HA](golion-locator-yandex.md).**

## Автозапуск на ГУ

1. В настройках Locator включите **«Автозапуск записи после включения ГУ»**.
2. Один раз сохраните настройки и начните запись.
3. Нажмите **«Разрешить фоновую работу / автозапуск»** и разрешите исключение из оптимизации батареи, если Android его предложит.
4. Если прошивка имеет собственный список автозапуска или фоновых приложений, добавьте туда Locator.

Проверьте запись после сна и повторного включения ГУ. **«Остановить запись»** отключает запись до следующего ручного запуска, включая автозапуск. Скорость первого определения GPS зависит от приёмника, прошивки и условий приёма. Если две минуты нет GPS-событий при включённом источнике, приложение повторяет запрос к Android.

## Экран приложения

- **Состояние:** запись, GPS/спутники, точность, давность точки, очередь и последняя передача.
- **Настройки:** канал, адрес/папка, ключи, интервал, QR и автозапуск.
- **Диагностика:** подробные счётчики, экспорт отчёта и проверка обновлений.

Кнопки записи закреплены внизу. «Назад» из настроек или диагностики сначала возвращает к состоянию. **«Сохранить настройки»** во время записи применяет текущую форму; просмотр разделов сам по себе её не сохраняет.

## Обновление через GitHub

1. Откройте **Диагностика → Проверить обновления**.
2. Если доступна новая версия, ознакомьтесь с изменениями и нажмите **«Скачать»**.
3. После загрузки приложение проверяет контрольную сумму и совместимость APK.
4. Разрешите установку из Jolion Locator, если Android запросит это, вернитесь в приложение и подтвердите установку в системном окне.

Проверка выполняется по нажатию, без скрытой установки. Стабильная версия предлагает стабильные выпуски; тестовая версия также видит предварительные. Нужен доступ к GitHub API и файлам GitHub Releases. Если сеть блокирует GitHub, скачайте APK на другом устройстве и установите вручную. Сохранённые данные остаются при обновлении поверх приложения.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| GPS выключен в Android | Разрешение местоположения и системный переключатель геолокации ГУ |
| Ожидание координат | Открытое место, спутники, работа навигации; сведения о спутниках могут приходить отдельно от координат |
| Навигация работает, Locator долго ждёт | Сохраните диагностику после 2–3 минут ожидания, укажите поведение навигации и модель ГУ |
| Очередь растёт, передачи нет | Интернет, адрес HTTPS/токен Диска; запись остаётся локально |
| HTTP 401/403 | Совпадение ID и ключа, включение Locator в интеграции, доступность нужного HA |
| Передано на Диск, а HA не обновился | Публичная ссылка, ID/ключ, статус чтения папки и доступ HA к Яндексу |
| После сна запись не возобновилась | Автозапуск Locator и ограничения фоновой работы прошивки |

Для обращения по проблеме сохраните JSON через **Диагностика → Сохранить диагностику**. Для ошибок маршрута скачайте точки выбранного периода из карточки HA. Эти два файла описывают разные части работы системы.
