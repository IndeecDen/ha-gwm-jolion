# Jolion Locator через Яндекс.Диск

**Схема:** ГУ/телефон → зашифрованные файлы на Диске → Home Assistant. Внешний адрес HA и входящие подключения к нему не требуются. Интернет нужен приложению для загрузки и HA для чтения папки.

Потребуются приложение [Jolion Locator](golion-locator.md), интеграция GWM Jolion, аккаунт Яндекса и отдельная папка Диска. Для начала удобно оставить интервал приложения и опроса HA по **30 секунд**.

## 1. Создайте папку

1. Войдите в [Яндекс.Диск](https://disk.yandex.ru/) под выбранным аккаунтом.
2. В корне создайте папку **JolionLocator**.
3. Нажмите **«Поделиться»**, включите доступ по ссылке с возможностью скачивания.
4. Скопируйте публичную ссылку вида `https://disk.yandex.ru/d/...`.

Нужна именно **папка**, а не документ. Её путь `/JolionLocator` и публичная ссылка — разные значения: путь вводится в приложение, ссылка — в HA. Поддерживается одна папка в корне с именем из латинских букв, цифр, `_` и `-`.

## 2. Получите OAuth-токен Яндекса

Токен даёт Locator возможность загружать файлы. Пароль Яндекса в приложение не вводится; публичная ссылка не заменяет токен.

### Создание доступа

1. Под **тем же аккаунтом, которому принадлежит папка**, откройте [Яндекс OAuth](https://oauth.yandex.ru/).
2. Нажмите **«Создать приложение»** → **«Для доступа к API или отладки»**. Можно открыть [форму напрямую](https://oauth.yandex.ru/client/new/).
3. В названии укажите, например, **Jolion Locator**, заполните контактную почту.
4. В списке доступов найдите **Яндекс.Диск REST API** и выберите **«Запись в любом месте на Диске»** — `cloud_api:disk.write`.
5. Создайте приложение и скопируйте его **ClientID**. Client secret в Locator не нужен.

Для приложений этого типа Яндекс использует адрес возврата `https://oauth.yandex.ru/verification_code`. Если у вас старое приложение с настраиваемым Redirect URI, укажите этот адрес в его настройках.

### Выдача токена

Откройте в браузере ссылку, заменив `ВАШ_CLIENT_ID` скопированным ClientID:

```text
https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID
```

Войдите под владельцем папки, подтвердите доступ к Диску и скопируйте показанный **OAuth-токен**. В Locator вставляется только значение токена — без слова `OAuth`, кавычек и пробелов. Если браузер показывает результат в адресе после `#access_token=`, копируйте значение до следующего `&`.

Токен и ClientID — разные строки. Если разрешения приложения были изменены, получите токен заново. Отозванный или истёкший токен замените в Locator; ID автомобиля и ключ Locator при этом менять не нужно.

Право `disk.write` распространяется на Диск аккаунта, а не только на одну папку. Для Locator можно использовать отдельный аккаунт. Не публикуйте токен и не отправляйте его вместе со скриншотами. Управлять выданными доступами можно в [Яндекс ID](https://id.yandex.ru/personal/data-access).

Официальная справка: [создание доступа к API](https://yandex.ru/dev/id/doc/ru/register-api), [получение отладочного токена](https://yandex.ru/dev/disk/poligon/).

## 3. Настройте приложение

В Jolion Locator → **Настройки**:

1. Выберите **«Через опубликованную папку Яндекс.Диска»**.
2. Укажите путь **`/JolionLocator`**.
3. Вставьте полученный **OAuth-токен**.
4. Укажите ID автомобиля и ключ Locator. Если вы уже использовали HTTPS, оставьте прежние значения.
5. Установите интервал отправки, например **30 секунд** (доступно 5–300).
6. Нажмите **«Показать QR подключения»** для переноса ID/ключа в HA или скопируйте их вручную.

HTTPS-адрес HA в этом режиме не используется. Ключ Locator шифрует файлы, OAuth-токен разрешает загрузку — оба нужны, они не заменяют друг друга.

## 4. Настройте Home Assistant

1. **Настройки → Устройства и службы → GWM Jolion → Настроить**.
2. Включите **«У меня установлен golion_locator»**.
3. Выберите **«Яндекс.Диск (публичная папка)»**.
4. Вставьте публичную ссылку из шага 1.
5. Заполните тот же ID и ключ Locator. Кнопка **«Ввести с QR»** позволяет использовать камеру или фото QR; после переноса сохраните форму.
6. Задайте интервал опроса папки, например **30 секунд**.
7. Для первого подключения оставьте автоочистку выключенной и сохраните настройки.

**Для чтения публичной папки OAuth-токен в HA не нужен.** Он понадобится только для необязательной автоочистки.

## 5. Проверьте передачу

1. В приложении нажмите **«Сохранить и начать запись»**, разрешите местоположение и дождитесь GPS-точки.
2. На экране **Состояние** должна обновиться последняя передача, а в папке появиться файлы `.jloc`.
3. В HA проверьте датчик **«Последние точки Locator»**, местоположение и карточку поездок. При необходимости скачайте диагностику интеграции.

**«Передано на Яндекс.Диск» означает загрузку на Диск, а не получение в HA.** HA забирает файлы по своему расписанию, поэтому между этими событиями есть задержка. При недоступности HA история остаётся на Диске и догружается после восстановления.

Интервал приложения разумно выбрать не больше интервала опроса HA. Уменьшение интервалов повышает частоту запросов; ограничения Яндекса и слабая сеть могут увеличить реальную задержку. Работа Яндекса в сети с «белым списком» зависит от оператора — проверьте именно SIM-карту автомобиля.

## Очередь и хранение

- Без интернета точки остаются в очереди на устройстве.
- После успешной загрузки архивного файла и свежего снимка на Диск точки удаляются из локальной очереди.
- Исторические файлы сохраняют поездки; `latest-<ID>.jloc` используется для свежей позиции.
- Повторный импорт не создаёт дубли точек. Содержимое файлов зашифровано; публично видны имена, размеры и даты файлов.
- Не меняйте ключ Locator до импорта старых файлов: новый ключ их не расшифрует.
- Без автоочистки файлы накапливаются. Удаляйте их вручную только после проверки импорта нужной истории в HA.

## Необязательная автоочистка

В настройках интеграции включите **«Перемещать загруженные файлы в корзину Диска»** и заполните:

- **Папка Яндекс.Диска с файлами Locator:** `/JolionLocator` — тот же путь, что в приложении.
- **OAuth-токен Яндекс.Диска (только для автоочистки):** токен с правом `cloud_api:disk.write`.
- **Защитный интервал перед удалением:** по умолчанию 24 часа, доступно 1–168 часов.

В корзину перемещаются только архивные файлы, импортированные этой установкой HA и старше выбранного интервала. Свежий снимок `latest` остаётся. При невозможности подтвердить импорт файл пропускается. Корзина занимает место, пока вы её не очистите.

Срок хранения поездок в HA настраивается отдельно. Автоочистка Диска не продлевает его. Токен сохраняется в настройках HA и скрывается при экспорте диагностики; резервные копии HA следует хранить как приватные данные.

## Смена канала и устранение проблем

Для перехода HTTPS ↔ Диск сохраните прежние ID/ключ, настройте обе стороны и примените новый канал в приложении. Накопленная локальная очередь того же автомобиля переводится на новый канал. Перед уходом с Диска дождитесь импорта уже загруженных файлов в HA.

| Проблема | Проверка |
|---|---|
| Файлы не появляются | Интернет ГУ, токен владельца папки с правом записи, существование папки и точность пути |
| Файлы есть, HA их не читает | Ссылка открывается без входа в Яндекс и разрешает скачивание; ID и ключ совпадают |
| Очистка недоступна | OAuth в HA, право записи, принадлежность папки аккаунту токена |
| Обновления идут медленно | Интервалы приложения/HA, сеть, ограничения API и объём накопленного архива |
