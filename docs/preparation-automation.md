# Автоматизации подготовки: Зима, Лето и свои профили

Профиль — это сохранённый набор параметров (температура, время двигателя и климата, подогревы сидений). Создание, выбор, копирование и удаление профилей **не отправляют команды автомобилю**: подготовку запускает кнопка **«Запустить профиль: …»** этого профиля или **«Запустить подготовку»** в карточке.

У каждого автомобиля есть отдельные кнопки профилей: Настройки → Устройства и службы → GWM Jolion → кнопки «Запустить профиль: Зима», «Запустить профиль: Лето», «Запустить профиль: Только водитель». В автоматизациях нажимайте свою кнопку — так не придётся вводить идентификаторы профилей, а при нескольких автомобилях кнопка не перепутает устройства.

Команды автомобилю выполняются по очереди: пока идёт предыдущая, новая отклоняется с ошибкой «Другая удалённая команда GWM уже выполняется». В автоматизациях используйте `mode: single`, чтобы не запускать подготовку повторно.

## Пример 1. Зимнее утро по будням

В 07:30 подготовка греет салон и сиденья только если на улице холоднее +5 °C.

```yaml
alias: "Jolion: зимнее утро"
triggers:
  - trigger: time
    at: "07:30:00"
conditions:
  - condition: state
    entity_id: binary_sensor.rabochiy_den     # помощник «Рабочий день»
    state: "on"
  - condition: numeric_state
    entity_id: sensor.ulichnaya_temperatura   # ваш уличный датчик или погода
    below: 5
actions:
  - action: button.press
    target:
      entity_id: button.zapustit_profil_zima  # кнопка своего профиля
mode: single
```

## Пример 2. Профиль по погоде: Зима или Лето

Один сценарий сам выбирает шаблон: ниже +5 °C — «Зима» (26 °C и подогрев сидений), иначе «Лето» (20 °C, без подогрева).

```yaml
alias: "Jolion: профиль по погоде"
triggers:
  - trigger: time
    at: "07:30:00"
actions:
  - choose:
      - conditions:
          - condition: numeric_state
            entity_id: sensor.ulichnaya_temperatura
            below: 5
        sequence:
          - action: button.press
            target:
              entity_id: button.zapustit_profil_zima
    default:
      - action: button.press
        target:
          entity_id: button.zapustit_profil_leto
mode: single
```

Порог и состав профилей меняются в карточке GWM Jolion — автоматизации при этом переписывать не нужно.

## Пример 3. Профиль, выбранный переменной

Если профиль задаётся не в сценарии, а, например, селектором на дашборде, сначала выберите его действием `gwm_jolion.manage_preparation_profile`, затем нажмите кнопку:

```yaml
actions:
  - action: gwm_jolion.manage_preparation_profile
    data:
      entry_id: "<ID записи интеграции>"
      action: select
      profile_id: "winter"
  - action: button.press
    target:
      entity_id: button.zapustit_vybrannyj_profil
```

- Действие `select` только меняет выбор и команд не шлёт; запускает по-прежнему нажатие кнопки.
- ID шаблонов: `winter` («Зима»), `summer` («Лето»), `driver` («Только водитель») — они сохраняются, пока профиль существует. Пустая строка в `profile_id` снимает выбор.
- Для собственных профилей проще нажимать их кнопку: ID копий и новых профилей — служебные, вводить их руками не нужно.
- `entry_id` обязателен при нескольких записях интеграции; при одном автомобиле выберите единственную предложенную запись.

## Подогрев сидений отдельно от профиля

Когда нужен только подогрев: `gwm_jolion.set_seat_heating` — `driver`/`passenger` от 0 до 3 (0 выключает), `operation_time` в минутах. Действие не запускает двигатель.
