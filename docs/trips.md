# Поездки

Карточка `custom:gwm-jolion-trips-card` показывает записанный маршрут и пробег за календарный период. В графическом редакторе выберите сущность «Местоположение» автомобиля GWM Jolion. Выбор дат и обновление карточки читают локальную историю и не отправляют команды автомобилю.

## Периоды и расчёт

- Сегодня: от 00:00 до последней доступной записи. Завершённый день: от 00:00 до 00:00 следующего дня. Используется часовой пояс Home Assistant, включая переходы летнего времени.
- Обе выбранные даты включены; максимальный период запроса — 366 дней. Пустая история не выдаётся за нулевой пробег. В компактном виде карта расположена сверху, пробег — под ней, даты открываются пиктограммой календаря. Приблизительный расчёт обозначен `≈`; единица измерения и даты доступны в подсказке при наведении на число.
- Если есть пары показаний одометра, учитываются их неотрицательные, правдоподобные разности внутри каждого дня. Сброс одометра не добавляет огромный пробег. При отсутствии пар используется приблизительная длина GPS-маршрута.
- У границ дня нет интерполяции: расстояние между последней записью вчера и первой сегодня не приписывается произвольно одному из дней. Поэтому число — пробег по доступным наблюдениям, а не гарантированное расстояние за полные сутки.
- Разрыв более 10 минут, отсутствие координат и невозможные скачки GPS разделяют линии маршрута. Короткие перемещения менее 30 метров между соседними точками не добавляются к GPS-оценке, чтобы уменьшить дрожание на стоянке. Редкий опрос, медленное движение и пропуски могут занижать эту оценку.
- Время записи — время получения ответа облака, не подтверждённое время GPS-фиксации автомобилем. Облако может возвращать старые данные. Для длинных периодов линия упрощается, но расчёт пробега выполняется до упрощения.

## Хранение и доступ

История начинает накапливаться с установки этой версии, затем пополняется при успешном опросе GPS, даже когда карточка закрыта. При остановленном Home Assistant история не записывается; старые поездки из приложения GWM не импортируются.

Поддерживается чтение уже сохранённых записей Home Assistant Recorder. История `device_tracker` включает изменения координат даже без смены состояния `home`/`not_home`; датчик пробега выбирается автоматически по реестру сущностей того же автомобиля. При необходимости задайте `odometer_entity` в YAML или выберите датчик в редакторе. Например:

```yaml
type: custom:gwm-jolion-trips-card
entity: device_tracker.zhulik_mestopolozhenie
odometer_entity: sensor.zhulik_probeg
```

Архив читается при выборе периода и дополняет данные до начала локального сбора; пересекающиеся записи не суммируются дважды. Если остался только архив пробега, число отображается без выдуманного маршрута. Если Recorder выключен или недоступен, используется локальная история. Требуется право просмотра обеих выбранных сущностей; чужой автомобиль подставить нельзя. Доступность прошлых дней зависит от включения сущностей в Recorder и его срока хранения. Долгосрочная статистика датчиков без сохранённых координат не позволяет восстановить маршрут; чтение её агрегатов здесь не реализовано.

Записи хранятся отдельно для каждого автомобиля в `/config/.storage/gwm_jolion_<entry_id>_trips.sqlite`. Файл содержит координаты и пробег; относитесь к резервным копиям как к личным данным. Записи не добавляются в JSONL поиска кодов или стандартную диагностику. Для чтения через карточку требуется авторизация Home Assistant и право просмотра выбранной сущности местоположения.

Настройка **«Хранение истории поездок, дней»** принимает 30–365, по умолчанию 90. Старые записи удаляются при следующем успешном сохранении; уменьшение срока необратимо сокращает историю. Файл сохраняется после перезапуска. При полном удалении интеграции его можно удалить вручную, предварительно сохранив резервную копию при необходимости.

Карта использует локально включённую библиотеку Leaflet и подложку OpenStreetMap. Браузер запрашивает тайлы видимой области: OpenStreetMap получает обычные запросы карты, включая IP и область просмотра. Координаты маршрута отдельным запросом туда не отправляются. Массовая загрузка тайлов и офлайн-кэш карты не реализованы. При отсутствии интернета пробег и линия маршрута доступны из локальной истории, но подложка может не загрузиться.
