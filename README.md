<h1 align="center">GWM Jolion для Home Assistant</h1>

<p align="center">
  Неофициальная интеграция Home Assistant для Haval Jolion с российской телематикой GWM Cloud: телеметрия, удалённое управление, климат, диагностика и встроенная Lovelace-карточка.
</p>

> [!WARNING]
> Проект не связан с Great Wall Motor, HAVAL или официальным приложением GWM. Используется неофициальный облачный API. Текущая версия — **0.1.0-alpha.9**.

## Что уже работает

Интеграция разрабатывается в первую очередь на реальном **Haval Jolion 2022 Premium** с российским GWM Cloud.

### Телеметрия

- авторизация в российском GWM Cloud;
- получение автомобиля из аккаунта;
- `getLastStatus` / `findStatus`;
- T-Box online/offline;
- GPS;
- общий пробег;
- остаток топлива в литрах;
- расчётный уровень топлива в процентах по объёму бака;
- запас хода;
- давление и температура всех четырёх шин;
- состояние двигателя;
- центральный замок;
- четыре двери;
- багажник;
- четыре окна с привязкой к физическому положению;
- состояния климата и ряда comfort-функций;
- диагностические GWM-коды и история неизвестных значений.

### Привязка окон

Для Jolion используются следующие коды:

| Код | Окно |
|---|---|
| `2210002` | переднее левое |
| `2210001` | переднее правое |
| `2210004` | заднее левое |
| `2210003` | заднее правое |

Значение `0` означает открытое окно, `1` — закрытое.

### Топливо и `oilQty`

Топливная телеметрия и `oilQty` — разные данные.

- фактическое количество топлива берётся из отдельной телеметрии GWM;
- процент топлива рассчитывается из литров и известного объёма бака;
- `oilQty` **не используется для расчёта топлива**;
- для российского API в интеграции `oilQty` трактуется как дискретный **уровень моторного масла GWM по шкале 0–8**;
- значение `oilQty` показывается сегментами и не переводится в проценты, пока точная физическая шкала GWM не подтверждена.

Например, наличие около 82–84% топлива одновременно с `oilQty = 4` показывает, что это поле нельзя трактовать как половину топливного бака.

## Удалённое управление

### Подтверждено

- запуск двигателя;
- остановка двигателя;
- закрытие автомобиля;
- открытие автомобиля;
- Home Assistant entity `lock`;
- открытие / закрытие багажника;
- закрытие всех окон;
- моргание фарами;
- звуковой сигнал;
- фары + звуковой сигнал;
- принудительное обновление данных.

Удалённый запуск двигателя поддерживает время работы **5–30 минут**.

### Реализовано, но требует дополнительной проверки

- открытие всех окон;
- панорама открыть / закрыть;
- шторка панорамы открыть / закрыть;
- обогрев руля ON/OFF;
- обогрев заднего стекла ON/OFF;
- передний defrost;
- Cabin Clean / проветривание салона.

Экспериментальные команды используются осторожно: неподтверждённые payload для подогрева сидений и электрического обогрева лобового стекла интеграция не отправляет.

## Климат

Реализованы:

- entity `climate`;
- включение / выключение климата;
- температура **16–32 °C**;
- время работы **5–30 минут**;
- сохранение части настроек через `modifyVehicleRemoteCtlInfo`;
- диагностическое чтение `vehicleBasicsInfo`.

Для российского GWM Cloud используется команда `0x04`.

Климат пока считается экспериментальной частью проекта до завершения полного цикла физических тестов на разных комплектациях.

## Встроенная карточка
<p align="center">
  <img src="docs/card.png"">
</p>
Интеграция автоматически регистрирует собственную карточку:

```yaml
type: custom:gwm-jolion-card
```

Дополнительные frontend-зависимости вроде Mushroom не требуются.

Текущая карточка показывает и управляет:

- одной строкой заголовка вида `Haval Jolion Жулик 2WD`;
- именем автомобиля из GWM API;
- автоматическим определением `2WD / 4WD` для известных кодов Jolion;
- топливом в литрах и процентах;
- запасом хода и пробегом;
- запуском / остановкой двигателя и таймером автозапуска;
- центральным замком;
- багажником;
- окнами с перечислением конкретных открытых окон;
- панорамой и шторкой;
- климатом, температурой и таймером;
- обогревом руля;
- задним defrost;
- экспериментальным передним defrost;
- статусами подогрева водительского и пассажирского сидений;
- статусом электрического обогрева лобового;
- четырьмя шинами;
- T-Box / GSM / GPS;
- уровнем масла GWM в виде сегментной шкалы;
- временем последнего успешного обновления;
- результатом последней удалённой команды.

Большое изображение автомобиля из карточки удалено, чтобы не занимать полезное место.

### Определение привода

Для известных российских кодов Jolion:

| Код модификации | Привод |
|---|---|
| `CC7150BA00B` | 2WD |
| `CC7150BA01B` | 2WD |
| `CC7150BA24C` | 4WD |

Если код неизвестен, карточка не должна угадывать привод. Его можно задать вручную:

```yaml
type: custom:gwm-jolion-card
drivetrain: 4WD
```

## Диагностика и приватность

Интеграция содержит безопасный diagnostics export для Home Assistant.

Скрываются идентификаторы и чувствительные данные, включая:

- VIN;
- номер автомобиля;
- `vehicleId`;
- `shareId`;
- номер двигателя;
- IMSI / ICCID;
- телефон;
- пароль;
- PIN безопасности;
- access token;
- точные координаты.

Также сохраняется история неизвестных GWM-кодов: `first_seen`, `last_seen`, количество наблюдений и встречавшиеся значения.

`vehicleBasicsInfo` не должен ломать основной polling: его состояние отдельно диагностируется как `success_with_data`, `success_empty`, `unsupported` или `error`.

## Установка через HACS

1. Откройте **HACS**.
2. Перейдите в **⋮ → Custom repositories**.
3. Добавьте:

```text
https://github.com/IndeecDen/ha-gwm-jolion
```

4. Тип: **Integration**.
5. Установите **GWM Jolion**.
6. Полностью перезапустите Home Assistant.
7. Перейдите в:

```text
Настройки → Устройства и службы → Добавить интеграцию → GWM Jolion
```

8. Введите данные аккаунта российского приложения GWM.
9. Для удалённых команд включите их в параметрах интеграции и укажите PIN безопасности автомобиля.

Проект публикует обычные GitHub Releases (`0.1.0-alpha.8`, `0.1.0-alpha.9` и далее), поэтому HACS должен показывать номер версии, а не короткий SHA коммита.

## Ручная установка

Скопируйте:

```text
custom_components/gwm_jolion
```

в:

```text
/config/custom_components/gwm_jolion
```

После замены файлов выполните **полный перезапуск Home Assistant**.

## Отладка

```yaml
logger:
  logs:
    custom_components.gwm_jolion: debug
```

Для отчёта о тесте полезно указать модель, год, комплектацию, исходное состояние автомобиля, выполненную команду и результат. Не публикуйте VIN, пароль, PIN, access token, IMSI, ICCID, госномер и координаты.

## Безопасность

Удалённые команды физически меняют состояние автомобиля.

- тестируйте только на безопасно припаркованной машине;
- перед удалённым запуском убедитесь, что автомобиль находится в безопасных условиях;
- учитывайте cooldown GWM между командами;
- экспериментальные команды используйте только осознанно;
- проект не заменяет штатные средства безопасности автомобиля.
