# GWM Jolion — карта протокола

Этот файл фиксирует текущее состояние исследования телематики российского GWM Cloud для Haval Jolion.

Статусы:

- ✅ **confirmed** — поведение подтверждено на реальном Jolion;
- 🟢 **implemented** — функция реализована, но для стабильного релиза нужны дополнительные проверки;
- 🟡 **known_unverified** — назначение известно/ожидается, но enum или физическая привязка ещё проверяется;
- 🧪 **experimental** — используется только в экспериментальном функционале;
- ❓ **unknown** — точное назначение пока не установлено.

### Окна `2210001..2210004`

Полевой Protocol Capture показал, что это **многоуровневые**, а не бинарные статусы.

Для generic binary decoder в `0.1.0-alpha.19.3` используется только доказанная безопасная логика:

- `1` → закрыто;
- `2` / `3` → окно не закрыто;
- другие значения → unknown.

| Код | Физическая позиция | Статус | Подтверждённые значения |
|---|---|---|---|
| `2210001` | Переднее левое / водительское | ✅ confirmed | `1=closed`, `3=partial`, `2=full open` |
| `2210002` | Позиция уточняется | 🟡 known_unverified | `1=closed`, `2/3=not closed` |
| `2210003` | Позиция уточняется | 🟡 known_unverified | `1=closed`, `2/3=not closed` |
| `2210004` | Позиция уточняется | 🟡 known_unverified | `1=closed`, `2/3=not closed` |

До marker-теста оставшихся трёх окон новые friendly-позиции им не назначаются.

## ACC / wake

В отдельном тесте ACC двигатель оставался `2016001=0`, но GWM начал отдавать свежую телеметрию. Значение `2016001=1` пока не наблюдалось. Отдельный пользовательский sensor ACC пока не создаётся.

План marker-теста: `VEHICLE_SLEEP → DOOR_WAKE → IGNITION_ACC → ENGINE_RUNNING → ENGINE_STOPPED → VEHICLE_LOCKED`.

## Protocol Capture

Начиная с `alpha.18` интеграция умеет писать JSONL-сессии для физических тестов. `alpha.19` добавил marker service и экспорт в стандартную диагностику, `alpha.19.1` сохраняет baseline + последние 5000 refresh, `alpha.19.2` добавил schema 2 с safe metadata/structure inventory.

Новый сигнал или команда не переводится в **confirmed**, пока её поведение не подтверждено на физическом автомобиле. До этого пользовательские сущности остаются raw/diagnostic или experimental.
