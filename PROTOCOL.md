# GWM Jolion — карта протокола

Этот файл фиксирует текущее состояние исследования телематики российского GWM Cloud для Haval Jolion.

Статусы:

- ✅ **confirmed** — поведение подтверждено на реальном Jolion;
- 🟢 **implemented** — функция реализована, но для стабильного релиза нужны дополнительные проверки;
- 🟡 **known_unverified** — назначение сигнала известно по открытым реализациям/картам, enum или поведение ещё проверяется;
- 🧪 **experimental** — используется только в экспериментальном функционале;
- ❓ **unknown** — точное назначение пока не установлено.

> Позиции отдельных дверей и окон будут окончательно закреплены только после отдельного физического теста. Семантика `open/closed` уже известна.

## Неизвестные коды

Начиная с `0.1.0-alpha.3`, интеграция автоматически собирает неизвестные GWM-коды в памяти координатора и включает их в безопасную диагностику Home Assistant:

- первое появление;
- последнее появление;
- последнее значение;
- набор наблюдавшихся значений;
- количество наблюдений.

Это позволит исследовать новые прошивки и комплектации без добавления каждого неизвестного кода вручную в логирование.

## Правило проекта

Новый сигнал или команда не переводится в статус **confirmed**, пока её поведение не подтверждено на физическом автомобиле. До этого пользовательские сущности должны оставаться raw/diagnostic или experimental.
